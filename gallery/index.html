How it works

  1. Install the skill

    Tell your agent to install it, or run npx skills add Vincentwei1021/video-shotcraft.

  2. Pick your shots

    Browse the library, select the cards you like, and copy their names — or let the agent pick along the energy curve.

  3. Ask for the video

    "Make a promo for my product with video-shotcraft." The agent handles screenshots, animation, pacing, and SFX.
